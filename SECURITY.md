# Security Policy

## Intended use

Personal Pass Generator is intended only for systems and accounts you own or
have explicit permission to assess. Generated wordlists can contain sensitive
personal information. Store and dispose of them according to the assessment's
data-handling rules.

## Reporting a vulnerability

Report security issues privately to `1200km@gmail.com`. Include reproduction
steps, impact, and affected versions. Do not open a public issue for an
unresolved vulnerability.
